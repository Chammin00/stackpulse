- **Summary:** Native Rust Windows 10/11 desktop shell and utility suite (no .NET, no Electron) bundling replacements for the taskbar (`topbar`), File Explorer (`rust-explorer`), NTFS search (`rust-search`), Task Manager (`rtaskmgr-win32`), disk cleaner, disk map, and photo viewer with one-click install and rollback.

#### How to Apply in Your Environment
- **Important Caution:** WinRust modifies Windows shell, taskbar, and search services, and `WinRust.exe` is **not code-signed** (SmartScreen will warn). Test inside a VM or spare machine first and ensure a Windows restore point is created before enabling `rust-explorer`.
- **Prebuilt Installer (No Rust Compiler Needed):** Although `cargo` is **not installed**, you can download `WinRust.exe` from release `v0.5.5` via **`gh`**:
  ```powershell

  ```
  Run `WinRust.exe` as Administrator and choose individual components (or click **Remove all** to restore Windows defaults). Building from source requires Rust (`winget install Rustlang.Rustup`).
