- **Platform Limitation (Not Native Windows):** `xnulinux` specifically requires an **arm64 Linux host** (such as an arm64 Linux VM or arm64 bare-metal system) plus a macOS VM disk image generated by Apple's installer — it cannot compile or load `xnu.ko` directly on x64 Windows.
- To clone and inspect the kernel patches and bridge modules locally using **`gh 2.97.0`**:
  ```powershell
  gh repo clone AFK-surf/xnulinux
  ```
  To run it, provision an arm64 Linux environment (on an arm64 host or cloud VM) and execute `scripts/vm-xnu-build.sh` and `scripts/xnulinux-boot.sh`.
