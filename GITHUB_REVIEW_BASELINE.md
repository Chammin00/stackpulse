# GitHub Resource Review Baseline

Whenever reviewing or summarizing GitHub repositories for this workspace, always include:

1. **What It Does** — Concise plain-English summary of core functionality.
2. **Environment Fit (Verified Windows Baseline)** — Whether it runs immediately on `git`, `gh`, `node v24.20.0`, `Python 3.12.10`, `uv 0.12.5`, and `winget`, via prebuilt Windows release, or requires an extra tool (`docker`, `bun`, `pnpm`, `cargo`, `go`, `ffmpeg`).
3. **Current Project Applications** — Which existing projects in `G:\My Drive\Antigravity\Projects\` can directly adopt or benefit from it.
4. **New Project Applications** — How it accelerates or upgrades future projects started in the workspace.
